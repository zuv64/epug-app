# E!Pug（イーパグ）

縦書きに対応した、EPUB／画像アーカイブ用のシンプルな読書アプリです。

## 対応している本の形式

- **EPUB**（`.epub`）
- **画像だけのZIPアーカイブ**（`.zip`）― マンガや画像集などをそのまま本として開けます

## 本の追加方法

1. アプリを開き、フォルダを選択します（Androidのフォルダ選択画面が開きます）
2. 選んだフォルダの中から `.epub` / `.zip` ファイルが自動的に一覧（本棚）に並びます
3. 本棚の見せ方は設定から「文字のみ」「サムネイル（小）」「サムネイル（大）」に切り替えられます
4. 並び順は「ファイル名（数字順）」「ファイル名（文字順）」「更新日時」から選べ、昇順・降順も切り替え可能です

一度開いた本は、続きのページ（章・スクロール位置）が自動的に記憶され、次に開いたときに続きから読めます。

## 読んでいるときの操作

### 画面タップ

画面は上下左右の帯（ゾーン）に分かれていて、タップした場所によって動作が変わります。ゾーンの境目は設定画面で調整できます。

- **中央をタップ**：既定ではメニュー（下メニュー）の表示/非表示を切り替え
- **左右の帯をタップ**：既定では前のページ／次のページへ送り
- 上下の帯は目次・しおりなど、別の操作にも割り当てられます

それぞれのタップ位置に割り当てる動作（前ページ／次ページ／メニュー開閉／目次／しおり一覧／しおり追加／何もしない）は設定から変更できます。

### 指でスライド

ページめくり方式（後述）のときは、画面を指で左右にドラッグしてページをめくれます。少しだけ動かして指を離すとキャンセルされ、ある程度はっきり動かすとそのままページが送られます。

### 音量ボタン

音量の上/下ボタンにも、ページ送りを割り当てられます（既定：上＝前ページ、下＝次ページ）。設定で「なし」にすることもできます。

## 表示設定

設定画面から、読み心地に合わせて次の項目を調整できます。

- **文字の大きさ**
- **縦書き／横書き**
- **ページめくり方式／スクロール方式**（ページ単位でめくるか、連続してスクロールするか）
- **行間の広さ**
- **余白の大きさ・色**（灰／白／薄灰／濃灰／黒）
- **余白にタイトルやページ番号を表示するか**
- **ダークモード**
- **縦書き時の配色プリセット**
- **横長の挿絵を見開き（2ページ）として分割表示するか**
- **下メニュー・設定画面の透明度**
- **本棚の見せ方・並び順**

## しおり・目次・履歴

- 現在の位置に**しおり**を追加して、あとで一覧から呼び出せます
- EPUBの**目次**からジャンプできます
- 読んだ位置の**履歴**を振り返れます

## その他

- アプリのランチャーアイコンは、設定から2種類（アイコンA／アイコンB）に切り替えられます
