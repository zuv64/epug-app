# E!Pug（イーパグ）

縦書きに対応した、EPUB／画像アーカイブ用のシンプルな読書アプリです。

## 対応している本の形式

- **EPUB**（`.epub`）
- **書庫**（`.zip` / `.rar` / `.7z` / `.cbz` / `.cbr` / `.cb7`）
  - 画像だけの書庫は、マンガや画像集としてそのまま1冊の本として開けます
  - 書庫の中に入っているEPUBや書庫（2段まで）も、1冊ずつ本棚に並びます

## 本の追加方法

1. 本棚の上部にあるフォルダ名をタップし、フォルダを選択します（Androidのフォルダ選択画面が開きます）
2. 選んだフォルダの中の対応ファイルが自動的に一覧（本棚）に並びます。サブフォルダはフォルダとして表示され、中に入って見られます
3. 本棚の上部のボタンから、次の操作ができます
   - 一つ上のフォルダへ戻る
   - 見せ方の切り替え（「文字」「サムネイル（小）」「サムネイル（中）」「サムネイル（大）」）
   - 並び順の切り替え（「タイトル（数字）」「タイトル（文字）」「更新日時」、昇順・降順）
   - タイトルでの絞り込み
   - 設定を開く

一度開いた本は、読んでいた位置が自動的に記憶され、次に開いたときに続きから読めます。本棚には本ごとの読み進み具合がバーで表示されます。

## 読んでいるときの操作

### 画面タップ

画面は上下左右の帯（ゾーン）に分かれていて、タップした場所によって動作が変わります。

- **上の帯**：本棚へ戻る
- **下の帯**：下メニュー（ページ操作）の表示/非表示を切り替え
- **左の帯**：次のページ
- **右の帯**：前のページ
- **中央**：設定を開く

ゾーンの境目は、設定の「タップ範囲」タブで線をつまんで調整できます。

目次ページなど、本の中のリンクはタップするとその場所へ移動します。

### 指でスライド

ページ方式（後述）のときは、画面を指で左右にドラッグしてページをめくれます。章の端では、そのまま隣の章へ進みます。少しだけ動かして指を離すとキャンセルされ、ある程度はっきり動かすとそのままページが送られます。

### 下メニュー

- ページ位置のスライダー
- 次のページ／前のページ、最初のページ／最後のページ
- 本棚の並びで前の本／次の本を開く

### 音量ボタン

音量の上/下ボタンにも、ページ送りを割り当てられます（既定：上＝前ページ、下＝次ページ）。設定で「なし」にすることもできます。

### 戻るキー

設定や下メニューを開いているときはそれを閉じ、それ以外は本棚へ戻ります。

## 表示設定

本文は縦書きで表示します。設定画面の「基本設定」タブから、次の項目を調整できます。

### ビュアー

- **テーマ**（ライト／ダーク。本文のみ。本棚は端末の設定に従います）
- **文字サイズ**
- **本文の高さ**（画面の高さに対する本文の割合）
- **本文の行間**
- **左右余白**（S／M／L／XL）
- **上余白にタイトルを表示するか**
- **下余白にページ番号を表示するか**
- **横長の挿絵を見開き（2ページ）として分割表示するか**
- **挿絵の外側の余白を詰めて表示するか**
- **めくり方**（ページ／スクロール）
- **ヘッダ・フッタ（上下余白）の色**（白／薄灰／灰／濃灰／黒）

### 書籍一覧

- **EPUBタイトル表示**（ファイル名／EPUB内のタイトル）
- **タイトルスクロール**（収まらないタイトルを流すか）
- **一覧のキャッシュ再作成**

### システム設定

- **メニュー透過率**（下メニュー・設定画面の透け具合）
- **回転**（縦／横／自動）
- **ボリュームボタン**の割り当て（前ページ／次ページ／なし）
- **アイコン**（ランチャーアイコンを2種類から選択）

## 履歴

設定画面の「履歴」タブに、最近開いた本が並びます。タップするとその本を開けます。
